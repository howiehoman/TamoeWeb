## Description

Every guest, thoughtfully planned.

TAMOE is a private, local-first wedding guest-list planner for couples organizing one or more celebrations. Add each guest once, then keep the details for every celebration connected in one clear place.

Plan with clarity

• See every guest across all celebrations
• Set a target headcount for each celebration
• Keep Number of Pax visible as plans change
• Organize guests with built-in or custom categories
• Use Must Invite, Maybe, and Optional Priority Levels
• Add notes for dietary needs, accessibility details, family context, and reminders

Find the right person quickly

Search by typing or use optional voice search. Filter by celebration, category, or Priority Level when the list grows.

Prepare the list for vendors

Choose the celebrations, categories, and fields you need, then export the guest list as PDF or an Excel and Numbers-compatible spreadsheet. Share it with the people helping bring the wedding together.

Private by design

TAMOE does not require an account. Guest-list information is stored locally on your iPhone. The app includes no advertising or cross-app tracking.
