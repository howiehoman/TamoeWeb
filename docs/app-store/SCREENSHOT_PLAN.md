# App Store screenshot plan

## Current assets

The seven existing screenshots in `public/app-screens` are genuine simulator
captures at 1206 by 2622 pixels. This is an accepted 6.3-inch portrait size.

Apple allows one to ten screenshots in PNG, JPG, or JPEG format. Images must not
contain an alpha channel. A complete 6.9-inch set is preferred for the primary
iPhone product page. Accepted 6.9-inch portrait sizes include:

- 1260 by 2736
- 1290 by 2796
- 1320 by 2868

Do not stretch the current screenshots. Capture a new set from a matching
6.9-inch simulator so text and controls remain native.

If the app continues to support iPad, a 13-inch iPad set is required. Accepted
portrait sizes include 2064 by 2752 and 2048 by 2732.

## Recommended iPhone order and captions

Use non-sensitive dummy data and capture the submitted Release candidate.

1. **Every guest in one shared list**
   Show All Events with a guest attending more than one celebration.
2. **Keep every celebration on track**
   Show one celebration with its planned total and target headcount.
3. **Plan each invitation clearly**
   Show Category, Priority Level, and Number of Pax for one guest.
4. **Keep notes with the right guest**
   Show multiple specific notes attached to the selected guest.
5. **Create the categories your wedding needs**
   Show built-in and custom guest categories without any private names.
6. **Search and filter a growing list**
   Show a useful category or Priority Level filter result.
7. **Export a list ready to share**
   Show the export format, event, category, and field choices.

## Capture rules

- Use a clean status bar and consistent time.
- Use the same language across the complete set.
- Do not show real phone numbers, addresses, email addresses, or private notes.
- Do not show debug overlays, simulator chrome, cursor, or Xcode.
- Do not add device frames that obscure app content.
- Keep captions accurate to the submitted build.
- Keep the most important UI away from caption overlays if marketing text is
  added later.
- Verify every file's pixel dimensions and confirm it has no alpha channel.
- Upload screenshots in the intended order and preview the product page before
  submission.

## App preview video

An App Preview is optional for version 1.0. Prioritize polished screenshots and
a stable release first. If a video is added, it must show the actual app and
follow Apple's device-size and duration specifications.
